About

A directory that shows its work.

German Unicorns is a public register of Germany's currently private companies valued at a billion euros or more, built so that every figure on it can be checked against a public, dated source rather than taken on trust.

Why this exists

Germany is one of Europe's largest technology markets, and Europe's own venture and scale-up capital has become a live policy question in its own right. That debate deserves a factual, checkable baseline rather than a round number repeated without its source. This site exists to provide that baseline for one country: every company listed is verified against a public announcement, every valuation carries the date it was true, and every claim is open to correction. See the Method page for the exact rules that enforce this.

Free and open

The site costs nothing to run and nothing to read. There is no paywall, no account, and no advertising. The code and the entire dataset — one JSON file per company — are public on GitHub at github.com/LW7776/Unicorn-Germany, where every past change is visible as a diff against the file it edited. Nothing here relies on a paid API or a licensed data feed.

How updating works

An automated scan runs monthly and can also be triggered on demand. It reads the RSS feeds of the allowlisted trade press, matches articles against tracked company names and trigger words — raises, Series, valuation, unicorn, IPO, insolvency — and flags candidate updates: German companies newly reported above the €1B threshold, or existing companies with a new figure to record. The scan opens or updates a GitHub issue listing what it found, with the headline, publication and link for each candidate.

Nothing is published from that issue automatically. A person reads the flagged articles, proposes the JSON edit with its source quote attached, and the site's validation checks run against it before it can be merged. Every update — automated candidate or manual correction — lands as a pull request and a reviewable diff, with a human as the approval gate.

Corrections

If something here is wrong, out of date, or missing a source, open an issue on the GitHub issue tracker, or use the "Report an error" link in the footer of any page.
